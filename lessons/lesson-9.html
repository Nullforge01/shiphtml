Lesson 9: Flexbox Basics

Time: 10 min | Goal: Align items without float hacks or pain

What is Flexbox?

Flexbox = 1D layout system. Put display: flex on a parent. Its children become flex items that you can align easily.

.container {
  display: flex;
}

Main Axis vs Cross Axis

Default: main axis = left to right. Cross axis = top to bottom.

justify-content = main axis. align-items = cross axis.

1
2
3

^ justify-content: space-between

The 4 Key Properties

1. justify-content - Distribute items on main axis:

flex-start | center | space-between | space-around | flex-end

2. align-items - Align items on cross axis:

stretch | center | flex-start | flex-end

3. gap - Space between items. No margin hacks needed:

.container { gap: 16px; }

4. flex-direction - Flip axes. column = top to bottom:

.container { flex-direction: column; }
Mobile-first win: Flexbox + flex-direction: column on mobile, row on desktop. One layout, two breakpoints. No duplicate HTML.

Your Task

Build a nav bar in the editor:

1. .navbar → display: flex; + justify-content: space-between; + align-items: center;

2. .nav-links → display: flex; + gap: 16px;

3. Add padding: 16px; to .navbar
