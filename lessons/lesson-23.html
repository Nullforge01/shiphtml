Lesson 23: Objects

Time: 9 min | Goal: Group related data with key-value pairs

Object Basics

Arrays use numbers. Objects use named keys:

const user = {
  name: "Alex",
  age: 25,
  isAdmin: false
};

console.log(user.name); // "Alex"
console.log(user["age"]); // 25 bracket notation

Updating Properties

user.age = 26; // change
user.email = "alex@mail.com"; // add
delete user.isAdmin; // remove

Methods

Functions inside objects:

const user = {
  name: "Alex",
  greet: function() {
    return "Hi, I'm " + this.name;
  },
  // Shorthand method
  sayAge() {
    return `I'm ${this.age}`;
  }
};
user.greet(); // "Hi, I'm Alex"

Arrays of Objects

Most common data structure. APIs return this:

const users = [
  { id: 1, name: "Alex", score: 95 },
  { id: 2, name: "Sam", score: 88 },
  { id: 3, name: "Jordan", score: 92 }
];

users.map(u => u.name); // ["Alex", "Sam", "Jordan"]
users.find(u => u.id === 2); // {id: 2, name: "Sam", ...}
Destructuring: Pull values out quickly. const {name, age} = user; creates name and age variables. Cleaner than user.name everywhere.
