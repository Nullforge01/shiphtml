Lesson 16: Pseudo-classes

Time: 8 min | Goal: Style elements based on user interaction + position

Interaction States

:hover - Mouse over element
:focus - Keyboard tab or click into input
:active - While clicking/pressing
:visited - Links user already clicked

Example: Button States

.btn {
  background: #2563EB;
  transition: all 0.2s;
}
.btn:hover {
  background: #1D4ED8;
  transform: translateY(-2px);
}
.btn:active {
  transform: translateY(0);
}

Position Selectors

Target elements by their position without classes:

li:first-child { font-weight: 700; }
li:last-child { border: none; }
li:nth-child(odd) { background: #F1F5F9; }
li:nth-child(3n) { color: #2563EB; }

:nth-child Formula

an+b pattern. a = cycle size, b = offset:

1. 2n = every 2nd item: 2, 4, 6...

2. 3n+1 = 1, 4, 7...

3. -n+3 = first 3 items

Mobile rule: Always add :focus styles to match :hover. Mobile has no hover. Keyboard users need focus states. Never do outline: none without replacing it.

Your Task

Build an interactive list:

1. .item:hover → background: #EFF6FF; + transform: translateX(4px);

2. .item:active → background: #DBEAFE;

3. .item:nth-child(odd) → background: #F8FAFC;

4. .item:first-child → border-top: 2px solid #2563EB;

5. Add transition: all 0.2s; to .item for smooth animations

Hover, click, and check the zebra striping.
