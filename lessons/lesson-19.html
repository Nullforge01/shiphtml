Lesson 19: Animations

Time: 10 min | Goal: Create keyframe animations that run without user input

@keyframes

Define animation steps from start to end:

@keyframes slideIn {
  0% { 
    transform: translateX(-100%); 
    opacity: 0; 
  }
  100% { 
    transform: translateX(0); 
    opacity: 1; 
  }
}

Animation Property

Apply keyframes to an element:

.box {
  animation: slideIn 0.5s ease-out;
}

animation: name duration timing-function delay iteration-count direction fill-mode;

Common Values

1. iteration-count: infinite, 3, 1

2. direction: normal, reverse, alternate

3. fill-mode: forwards keeps end state, backwards applies start state during delay

.spinner {
  animation: spin 1s linear infinite;
}
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
Performance rule: Only animate transform and opacity. Animating width, height, top, left causes layout reflow and drops frames on mobile. Use transform: translateX() instead of left.

Animation vs Transition

Transition = Reacts to state change. Needs trigger like :hover.

Animation = Runs automatically. Can loop. More control.

Accessibility: Respect prefers-reduced-motion. Some users get dizzy from animations. 
@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; }
}

Your Task

Build a loading screen with 3 animations:

1. @keyframes fadeIn → 0% {opacity: 0} to 100% {opacity: 1}

2. .logo → animation: fadeIn 0.8s ease-out;

3. @keyframes pulse → 0%, 100% {transform: scale(1)} to 50% {transform: scale(1.1)}

4. .dot → animation: pulse 1.5s ease-in-out infinite;

5. @keyframes spin → from {transform: rotate(0)} to to {transform: rotate(360deg)}

6. .spinner → animation: spin 1s linear infinite;
