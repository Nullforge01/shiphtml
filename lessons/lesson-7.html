Lesson 7: Box Model

Time: 8 min | Goal: Control spacing around every element

Every Element is a Box

HTML elements have 4 layers from inside out:

Margin → Border → Padding → Content

The 4 Properties

1. padding - Space inside, between content and border:

.box { padding: 20px; }

2. border - Line around the element. Needs width + style + color:

.box { border: 2px solid #0F172A; }

3. margin - Space outside, pushes other elements away:

.box { margin: 16px; }

4. width/height - Size of content area only:

.box { width: 300px; height: 200px; }
Total width = width + padding-left + padding-right + border-left + border-right + margin-left + margin-right. Box model math matters.

Shorthand

You can set all 4 sides at once. Order: top, right, bottom, left = clockwise:

.box { 
  padding: 10px 20px 10px 20px; /* top right bottom left */
  margin: 16px 0; /* top/bottom 16px, left/right 0 */
}
