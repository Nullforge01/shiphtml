Lesson 8: Fonts & Text

Time: 7 min | Goal: Make text readable + beautiful

Font Properties

1. font-family - Which font to use. Always add fallbacks:

body { 
  font-family: 'Inter', Arial, sans-serif; 
}

2. font-size - Size of text. Use px, rem, or %:

h1 { font-size: 36px; }
p { font-size: 16px; }

3. font-weight - Thickness. 400 = normal, 700 = bold:

.bold { font-weight: 700; }

4. line-height - Space between lines. 1.6 = 160% of font-size:

p { line-height: 1.6; }

5. text-align - left, center, right:

.center { text-align: center; }

Google Fonts

Free fonts from fonts.google.com. Add to <head>:

<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">

Then use: font-family: 'Inter', sans-serif;

Mobile rule: Min 16px font-size for body text. Below 16px, iOS zooms the page when user taps inputs. Use 1.5+ line-height for readability.

Your Task

Style the article in the editor:

1. .article h1 → font-family: 'Playfair Display', serif; + font-size: 32px; + font-weight: 700;

2. .article p → font-family: 'Inter', sans-serif; + font-size: 16px; + line-height: 1.6;

3. .article .author → text-align: center; + color: #64748B;
