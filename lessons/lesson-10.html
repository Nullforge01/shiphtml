Lesson 10: Responsive Design

Time: 9 min | Goal: Make your site work on any screen size

The Viewport Meta Tag

Without this, mobile browsers pretend they're 980px wide. Always include it:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

^ Tells browser: use actual device width, don't zoom out.

Media Queries

CSS that only runs when screen matches a condition. Mobile-first = write mobile CSS first, then override for bigger screens:

/* Mobile first: 1 column */
.grid { 
  display: grid; 
  grid-template-columns: 1fr; 
  gap: 16px;
}

/* Tablet+ : 2 columns */
@media (min-width: 768px) {
  .grid { 
    grid-template-columns: 1fr 1fr; 
  }
}

/* Desktop: 3 columns */
@media (min-width: 1024px) {
  .grid { 
    grid-template-columns: 1fr 1fr 1fr; 
  }
}
Never use max-width. Always mobile-first with min-width. It forces you to think about constraints first. Desktop-first = bloated CSS.

Common Breakpoints

1. 640px = Large phones

2. 768px = Tablets

3. 1024px = Small laptops

4. 1280px = Desktops

Test on real phone: Resize browser ≠ real mobile. Use Chrome DevTools device toolbar or open on your phone via localhost tunnel.

Your Task

Make the card grid responsive:

1. .grid → display: grid; + grid-template-columns: 1fr; + gap: 16px;

2. Add @media (min-width: 640px) → .grid { grid-template-columns: 1fr 1fr; }

3. Add @media (min-width: 1024px) → .grid { grid-template-columns: 1fr 1fr 1fr; }
