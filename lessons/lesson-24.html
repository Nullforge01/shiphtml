Lesson 24: DOM Manipulation

Time: 12 min | Goal: Create, read, update, delete HTML with JS

Selecting Elements

const el = document.getElementById("app"); // by ID
const btn = document.querySelector(".btn"); // first match CSS
const items = document.querySelectorAll("li"); // all matches

querySelector is most flexible. Uses CSS selectors.

Creating Elements

const div = document.createElement("div");
div.textContent = "Hello";
div.className = "card";
div.id = "new-card";

Inserting Elements

const parent = document.querySelector("#app");
parent.appendChild(div); // add to end
parent.prepend(div); // add to start
parent.insertBefore(div, parent.firstChild);

Modifying Elements

el.textContent = "New text"; // text only, safe
el.innerHTML = "<b>HTML</b>"; // parses HTML, XSS risk
el.classList.add("active"); // add class
el.classList.remove("hidden"); // remove class
el.classList.toggle("dark"); // add if missing, remove if present
el.setAttribute("data-id", "123"); // set attribute
el.style.background = "red"; // inline style
innerHTML danger: Never do el.innerHTML = userInput. Users can inject <script> tags. Use textContent for user data. Only use innerHTML with trusted HTML strings you control.

Event Delegation

Listen on parent instead of 100 children:

document.querySelector("ul").addEventListener("click", (e) => {
  if (e.target.matches("li")) {
    e.target.classList.toggle("done");
  }
});
Batch DOM writes: Don't update DOM in a loop. Build HTML string/array first, then set innerHTML once. Or use DocumentFragment. Each DOM write triggers reflow.

Your Task

Build a dynamic tag creator:

1. const tags = [];

2. function renderTags() {

3.   const wrap = document.querySelector("#tags");

4.   wrap.innerHTML = tags.map((tag, i) =>

5.     `<span class="tag">${tag} <button data-i="${i}">×</button></span>`

6.   ).join('');

7. }

8. document.querySelector("#add").onclick = () => {

9.   const input = document.querySelector("#input");

10.   if (input.value) { tags.push(input.value); input.value = ""; renderTags(); }

11. };

12. document.querySelector("#tags").onclick = (e) => {

13.   if (e.target.matches("button")) { tags.splice(e.target.dataset.i, 1); renderTags(); }

14. };

Add tags, click × to remove. All DOM managed by JS.
