Lesson 20: JavaScript Intro

Time: 12 min | Goal: Add logic and interactivity with JS

HTML + CSS + JS

HTML = Structure. CSS = Style. JS = Behavior.

JS runs in the browser. No install needed. Add with <script> tag:

<script>
  console.log("Hello from JS!");
</script>

Variables

Store data with let or const:

let name = "Alex";  // can change
const age = 25;   // cannot change
console.log(name, age);

Open browser DevTools → Console to see console.log output.

DOM = Document Object Model

JS can read/change HTML. The page is a tree of elements:

const btn = document.getElementById("myBtn");
btn.textContent = "Clicked!";
btn.style.background = "red";

Events

Run code when user does something:

const btn = document.getElementById("myBtn");
btn.onclick = function() {
  alert("Button clicked!");
};
Script placement matters. Put <script> before </body> so HTML loads first. Or use DOMContentLoaded event. Otherwise getElementById returns null.
const by default: Use const unless you need to reassign. Prevents bugs. Only use let for counters/loops. Never use var - it's legacy.

Your Task

Make a click counter:

1. let count = 0; at top of script

2. const btn = document.getElementById("btn");

3. const display = document.getElementById("count");

4. btn.onclick = function() {

5.   count = count + 1;

6.   display.textContent = count;

7. };

Click the button and watch the number go up.
