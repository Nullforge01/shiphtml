Lesson 15: Positioning

Time: 9 min | Goal: Break elements out of normal flow when needed

The 5 Position Values

static - Default. Follows normal document flow.
relative - Offset from normal position. Space stays reserved.
absolute - Removed from flow. Positioned vs nearest positioned ancestor.
fixed - Removed from flow. Positioned vs viewport. Stays on scroll.
sticky - Relative until scroll point, then fixed.

relative + absolute Combo

Most common pattern. Parent = relative, child = absolute:

.card {
  position: relative;
}
.badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

^ Badge sits 12px from top-right of card, not the whole page.

top, right, bottom, left

Only work on positioned elements. Use 1-2 at a time:

.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

^ Centers element perfectly.

z-index

Controls stacking. Higher number = on top. Only works on positioned elements:

.header { z-index: 100; }
.modal { z-index: 1000; }
Avoid position abuse. 95% of layouts should use Flexbox/Grid. Use absolute only for badges, tooltips, dropdowns. Use fixed only for nav bars, modals.
Sticky nav: position: sticky; top: 0; on your nav makes it stick to top when scrolling. No JS needed.

Your Task

Build a card with a "NEW" badge:

1. .card → position: relative;

2. .badge → position: absolute; + top: 12px; + right: 12px;

3. .sticky-note → position: sticky; + top: 20px;

4. Add z-index: 10; to .badge to ensure it's on top
