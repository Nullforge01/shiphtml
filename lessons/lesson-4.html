Lesson 4: Lists

Time: 5 min | Goal: Structure content with bullets + numbers

Unordered Lists: <ul>

Use <ul> when order doesn't matter. Renders with bullets. Each item uses <li>:

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Ordered Lists: <ol>

Use <ol> when order matters. Renders with numbers 1, 2, 3:

<ol>
  <li>Wake up</li>
  <li>Code</li>
  <li>Sleep</li>
</ol>

Nested Lists

You can put a list inside another <li> to create sub-items:

<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
Rule: <li> can ONLY live inside <ul> or <ol>. Never use <li> alone. Browser will break.

When To Use Which

1. <ul> = Nav menus, feature lists, tags. No sequence.

2. <ol> = Steps, rankings, instructions. Order matters.

Your Task

In the editor → Build 2 lists:

1. An <ol> with your top 3 goals for learning code

2. A <ul> with 3 skills you want. Nest another <ul> inside one <li> with 2 sub-skills

Click Run to see bullets + numbers render.
