Lesson 14: CSS Grid Intro

Time: 10 min | Goal: Build 2D layouts with rows AND columns

Grid vs Flexbox

Flexbox = 1D. Row OR column. Good for nav bars, centering.

Grid = 2D. Rows AND columns. Good for full page layouts, galleries.

Basic Grid Setup

Parent gets display: grid. Define columns with grid-template-columns:

.container {
  display: grid;
  grid-template-columns: 200px 1fr 100px;
  gap: 16px;
}

^ 3 columns: 200px fixed, 1 fraction of leftover space, 100px fixed.

The fr Unit

fr = fraction. Splits available space:

grid-template-columns: 1fr 1fr 1fr;

^ 3 equal columns. Better than 33.33% because it handles gaps correctly.

Repeat shortcut: repeat(3, 1fr) = 1fr 1fr 1fr

gap vs margin

gap: 16px adds space between grid items only. No margin hacks needed. No extra space on edges.

Mobile-first Grid: Start with grid-template-columns: 1fr for mobile. Add columns at breakpoints. Grid + media queries = responsive without JS.

Your Task

Build a dashboard layout:

1. .dashboard → display: grid; + grid-template-columns: 1fr; + gap: 16px;

2. @media (min-width: 768px) → .dashboard { grid-template-columns: 250px 1fr; }

3. @media (min-width: 1024px) → .dashboard { grid-template-columns: 250px 1fr 300px; }

Resize preview: 1 col → 2 col → 3 col layout.
