Lesson 3: Links & Images

Time: 7 min | Goal: Connect pages + show pictures

Links: The <a> Tag

The <a> tag = anchor. It makes text clickable. href = where it goes.

<a href="https://google.com">Go to Google</a>
<a href="lesson-2.html">Previous Lesson</a>

2 types of paths:

1. Absolute: https://example.com = full URL, goes anywhere

2. Relative: lesson-2.html = file in same folder. ../index.html = go up one folder

Target blank: Add target="_blank" to open link in new tab. <a href="https://google.com" target="_blank">Google</a>

Images: The <img> Tag

<img> is self-closing. No </img>. Needs 2 attributes:

<img src="photo.jpg" alt="Description of photo">

1. src = source. URL or file path to image

2. alt = alt text. Describes image for screen readers + shows if image fails

Always add alt text. Blind users need it. Google uses it for image search. Empty alt="" = decorative image only.
