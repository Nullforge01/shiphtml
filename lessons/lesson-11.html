Lesson 11: Forms

Time: 10 min | Goal: Collect user data with inputs

Basic Form Structure

<form> wraps inputs. <label> describes each input. <input> collects data:

<form>
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <button type="submit">Send</button>
</form>

Input Types

type changes keyboard on mobile + validation:

1. text = normal keyboard

2. email = shows @ key, validates email format

3. password = hides characters

4. number = number keyboard

<input type="email" placeholder="you@example.com">

Labels = Accessibility

for="id" on label must match id on input. Clicking label focuses input. Screen readers need it.

<label for="email">Email</label>
<input type="email" id="email">
Never skip labels. Placeholder is not a label. It disappears when user types. Blind users can't see placeholders.

Button Types

1. type="submit" = sends form data

2. type="button" = does nothing unless JS added

3. type="reset" = clears form

Mobile rule: Inputs need font-size: 16px; minimum or iOS zooms the page. Add autocomplete="email" to help users autofill.

Your Task

Build a signup form in the editor:

1. <label> + <input type="text"> for Name

2. <label> + <input type="email"> for Email

3. <label> + <input type="password"> for Password

4. <button type="submit"> with text "Sign Up"

5. Add required to all inputs

Click Run then try submitting empty fields.
