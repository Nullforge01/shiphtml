Lesson 5: CSS Selectors

Time: 8 min | Goal: Target HTML with CSS to style it

What is CSS?

CSS = Cascading Style Sheets. HTML = structure, CSS = looks. You write CSS in <style> tags or separate files.

The 3 Basic Selectors

1. Element selector - targets all tags of that type:

p { 
  color: blue; 
}

^ Makes ALL <p> tags blue.

2. Class selector - targets class="name". Starts with .:

.highlight { 
  background: yellow; 
}

^ Targets <p class="highlight"> or any element with that class.

3. ID selector - targets id="name". Starts with #:

#header { 
  font-size: 32px; 
}

^ Targets <h1 id="header">. ID must be unique per page.

Specificity rule: ID beats Class beats Element. If #header and .title both target same element, ID wins.

How CSS Works

selector {
  property: value;
  property: value;
}

Selector picks the HTML. Property = what to change. Value = how to change it.

Pro tip: Use classes for reusable styles. Use IDs for one-off things like #main-nav. Never style with IDs unless you must.
