Lesson 25: Final Project

Time: 20 min | Goal: Ship a real app using everything you learned

Notes Dashboard

Build a full CRUD app. Create, read, update, delete notes. Uses Grid, Flexbox, arrays, objects, DOM, events.

Requirements:
  1. CSS Grid layout: sidebar + main content
  2. Add notes with title + body
  3. Store notes in array of objects
  4. Render notes as cards with map()
  5. Click card to edit in sidebar
  6. Delete button on each card
  7. Save to localStorage so refresh persists
  8. Transitions on hover

Data Structure

const notes = [
  { 
    id: 1, 
    title: "Ship it", 
    body: "Done is better than perfect",
    created: 1698765432000 
  }
];

localStorage

Persist data between sessions:

// Save
localStorage.setItem("notes", JSON.stringify(notes));

// Load
const saved = localStorage.getItem("notes");
const notes = saved ? JSON.parse(saved) : [];
You made it. 25 lessons. HTML, CSS, JS, DOM, Grid, Flexbox, Functions, Arrays, Objects. You can build anything now. This project proves it. Ship this, then build your portfolio.

Your Task

Complete the starter code:

1. Load notes from localStorage on start

2. addNote() - create object, push to array, save, render

3. renderNotes() - map array to HTML cards

4. selectNote(id) - find note, populate sidebar form

5. updateNote() - modify object in array, save, render

6. deleteNote(id) - filter array, save, render

7. Wire all click handlers

Add notes, click to edit, delete, refresh page. Data persists.
