Lesson 6: Colors & Backgrounds

Time: 6 min | Goal: Make your page actually look good

3 Ways to Write Colors

1. Named colors - 140 built-ins like red, blue, coral:

p { color: orange; }

2. Hex codes - #RRGGBB. Most common. #FF6A00 = SHIPhtml orange:

h1 { color: #FF6A00; }

3. RGB - rgb(red, green, blue) from 0-255:

div { background-color: rgb(37, 99, 235); }
#FF6A00

#0F172A

color vs background-color

color = text color. background-color = behind the text:

.banner {
  color: white;
  background-color: #0F172A;
  padding: 20px;
}
Contrast matters: Use coolors.co to check if text is readable. White on yellow = bad. White on #0F172A = good.
