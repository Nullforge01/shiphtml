Lesson 12: Tables

Time: 8 min | Goal: Display tabular data correctly

Table Structure

Tables are for data, not layout. Use flexbox/grid for layout.

<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Role</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alex</td>
      <td>Dev</td>
    </tr>
  </tbody>
</table>

The Tags

1. <table> - Wraps everything

2. <thead> - Table header section

3. <tbody> - Table body section

4. <tr> - Table row

5. <th> - Table header cell. Bold + centered by default

6. <td> - Table data cell. Normal text

Never use tables for layout. Screen readers read tables row by row. Using tables for design breaks accessibility. Use CSS Grid or Flexbox instead.

Styling Tables

Tables need CSS to look good. Remove default spacing:

table {
  width: 100%;
  border-collapse: collapse;
}
th, td {
  padding: 12px;
  text-align: left;
  border-bottom: 1px solid #E2E8F0;
}
th {
  background: #F1F5F9;
  font-weight: 600;
}
Mobile tables: Tables suck on phones. Use overflow-x: auto on a wrapper div to make them scrollable horizontally. Or stack cells on mobile with flexbox.
