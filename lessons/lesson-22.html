Lesson 22: Arrays & Loops

Time: 10 min | Goal: Store lists of data and loop through them

Arrays

Ordered lists. Zero-indexed:

const fruits = ["apple", "banana", "orange"];
console.log(fruits[0]); // "apple"
console.log(fruits.length); // 3

fruits.push("mango"); // add to end
fruits.pop(); // remove from end

Looping

1. for...of - Best for arrays. Clean syntax:

for (const fruit of fruits) {
  console.log(fruit);
}

2. forEach - Array method. Gives index:

fruits.forEach((fruit, i) => {
  console.log(i + ": " + fruit);
});

3. for loop - Full control:

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

Array Methods

const nums = [1, 2, 3];

nums.map(n => n * 2); // [2, 4, 6] transform
nums.filter(n => n > 1); // [2, 3] select
nums.find(n => n === 2); // 2 first match
nums.includes(3); // true check exists
Use map for UI: Turn array of data into array of HTML. users.map(u => `<li>${u.name}</li>`). Then join('') to combine. Avoid for loops for rendering.
