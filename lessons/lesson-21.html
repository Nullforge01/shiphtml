Lesson 21: Functions

Time: 10 min | Goal: Write reusable code with functions

Why Functions?

Don't repeat yourself. Package code you use multiple times:

// Bad: repeated code
console.log("Hello Alex");
console.log("Hello Sam");
console.log("Hello Jordan");

// Good: function
function greet(name) {
  console.log("Hello " + name);
}
greet("Alex");
greet("Sam");
greet("Jordan");

Function Anatomy

function add(a, b) {  // a, b = parameters
  const result = a + b;
  return result;      // send value back
}
const sum = add(5, 3); // 5, 3 = arguments
console.log(sum);      // 8

Arrow Functions

Shorter syntax. Modern JS:

const add = (a, b) => {
  return a + b;
};

// One-liner: implicit return
const add = (a, b) => a + b;

Scope

Variables inside functions stay inside:

function test() {
  const secret = "hidden";
}
console.log(secret); // Error: secret not defined
Naming: Functions do things. Use verbs: getUser(), calculateTotal(), showModal(). Not user() or data(). Return early to avoid nesting.

Your Task

Build a tip calculator:

1. function calculateTip(bill, percent) {

2.   const tip = bill * (percent / 100);

3.   return tip;

4. }

5. const updateUI = () => {

6.   const bill = Number(document.getElementById("bill").value);

7.   const tip = calculateTip(bill, 15);

8.   document.getElementById("tip").textContent = "$" + tip.toFixed(2);

9.   document.getElementById("total").textContent = "$" + (bill + tip).toFixed(2);

10. }

11. Wire it: document.getElementById("calc").onclick = updateUI;

Type a bill amount, click Calculate.
