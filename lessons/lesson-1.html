Lesson 1: HTML Tags & Structure

Time: 5 min | Goal: Build your first webpage skeleton

What is HTML?

HTML = HyperText Markup Language. It tells the browser what each piece of content is. A heading? A paragraph? A button? You wrap text in tags to define it.

The 3 Required Tags

Every HTML page needs this basic structure:

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    Your content goes here
  </body>
</html>

Breakdown:

1. <!DOCTYPE html> = Tells browser this is HTML5. Always first line.

2. <html> = Root element. Everything lives inside.

3. <head> = Metadata. Title, CSS links, fonts. Not visible on page.

4. <body> = Visible content. Headings, text, images go here.

Key rule: Most tags come in pairs. <body> opens, </body> closes. The / means "end tag". Forget the / and your page breaks.

Your Task

In the editor → Change the text inside <h1> to your name. Then click Run. You should see your name in the preview below.

Add a <p> tag under the <h1> with any sentence you want. Example: <p>I build websites.</p>
