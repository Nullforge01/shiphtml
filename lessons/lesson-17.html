Lesson 17: Pseudo-elements

Time: 8 min | Goal: Style parts of elements or inject content with CSS

::before and ::after

Inject content without touching HTML. Must have content property:

.quote::before {
  content: "“";
  font-size: 48px;
  color: #2563EB;
}
.quote::after {
  content: "”";
}

Common Uses

1. Icons - Add arrows, bullets without images

2. Decorative lines - Underlines, separators

3. Tooltips - Extra info on hover

4. Clearfixes - ::after { clear: both; }

Other Pseudo-elements

::first-letter - Style first letter like magazines

::first-line - Style first line of text

::selection - Style highlighted text

p::first-letter {
  font-size: 48px;
  float: left;
  line-height: 1;
}
::selection {
  background: #FEF3C7;
}
Double colon :: Modern syntax. Single :before still works but ::before is correct. Pseudo-classes use :, pseudo-elements use ::.
Content property: content: ""; creates empty box you can style. content: attr(data-text); pulls from HTML attributes. Can't select ::before text with mouse.

Your Task

Style a quote block with pseudo-elements:

1. .quote::before → content: "“"; + font-size: 64px; + color: #2563EB; + position: absolute;

2. .quote::after → content: ""; + width: 40px; + height: 3px; + background: #2563EB;

3. .quote p::first-letter → font-size: 48px; + font-weight: 700;

4. ::selection → background: #FEF3C7;

Try highlighting text to see selection color.
