Lesson 18: Transitions

Time: 7 min | Goal: Animate CSS changes smoothly

Without Transition

Hover states snap instantly. Feels cheap:

.btn {
  background: blue;
}
.btn:hover {
  background: darkblue;
}

With Transition

Add transition to animate between states:

.btn {
  background: blue;
  transition: all 0.2s ease;
}
.btn:hover {
  background: darkblue;
  transform: translateY(-2px);
}

Transition Syntax

transition: property duration timing-function delay;

1. property - all, background, transform, opacity

2. duration - 0.2s, 200ms

3. timing-function - ease, linear, ease-in-out

4. delay - 0.1s wait before starting

What to Animate

GPU-fast: transform, opacity. 60fps on mobile.

CPU-slow: width, height, margin, box-shadow. Causes reflow.

Never animate all properties blindly. transition: all 0.3s is lazy. Specify what changes: transition: transform 0.2s, background 0.2s. Animating width on 100 items kills mobile performance.

Transform Functions

transform doesn't trigger layout recalculation:

.card:hover {
  transform: scale(1.05) translateY(-4px);
}

^ Scales up 5% and moves up 4px. Smooth on phones.

Duration rule: 0.15s-0.3s feels instant but smooth. Under 0.15s = invisible. Over 0.5s = sluggish. ease-out for entrances, ease-in for exits.

Your Task

Make these cards feel premium:

1. .card → transition: all 0.2s ease-out;

2. .card:hover → transform: translateY(-8px) scale(1.02); + box-shadow: 0 12px 24px rgba(0,0,0,0.1);

3. .btn → transition: transform 0.15s ease;

4. .btn:active → transform: scale(0.95);

Hover cards and click buttons. Feel the difference.
